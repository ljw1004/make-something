# 11. Outward, across and back

1. Blood-facing lining cells + Arterial wall → Arterial vessels — Blood-facing lining cells: preserve, Arterial wall: consume.

2. Tiny capillary tubes + Nearby body cells → Capillary bed — Tiny capillary tubes: transform, Nearby body cells: consume.

3. Blood-facing lining cells + Venous wall → Thin-walled veins — Blood-facing lining cells: preserve, Venous wall: consume.

4. Thin-walled veins + One-way valve flaps → Venous return — Thin-walled veins: transform, One-way valve flaps: consume.

5. Capillary bed + Venous return → Capillaries and venous return — Capillary bed: transform, Venous return: consume.

6. Arterial vessels + Capillaries and venous return → Body blood-vessel network — Arterial vessels: transform, Capillaries and venous return: consume.
