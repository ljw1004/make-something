# Opening and arm repair

The selected generated masters and exact built-in image-generation requests live in `sources/`. `produce.py` mechanically extracts and registers their runtime parts; it does not paint anatomical structures.

The cell repair adds an enclosing rear membrane surface, preserves installed component dimensions, and carries the completed cell into differentiation as one representative. BMP-2 and a single osteoblast extend that differentiation into bone construction. The soft/mineralized matrix pair preserves the recognizable cell and its scale. Arm stages share a coherent anterior-oblique specimen with distinct proximal biceps origins and a posterior triceps.

The initial arm, neuron and membrane requests used `../../opening/sources/cell.png` as a style reference; the membrane/carrier request also used the original sugar-carrier export. Later arm and neuron requests identify their preceding selected master in their filenames and request text. The bone-tissue pair references `bone-cell-master.png`. Sources used as edit inputs remain necessary production references even when a later output supersedes their direct runtime use.

See [independent outcomes](../outcomes.md) for accepted versions and unresolved findings. Production inspection is not independent acceptance.
