# 17. A response that remembers

1. Bacterial fragments with antigens + Resting lymphocytes → Activated matching lymphocyte — Bacterial fragments with antigens: consume, Resting lymphocytes: transform.

2. Activated matching lymphocyte + Living lymph node → Responding lymph node — Activated matching lymphocyte: consume, Living lymph node: transform.

3. Responding lymph node + Amino acids → Matching antibodies — Responding lymph node: preserve, Amino acids: consume.

4. Matching antibodies + Bacteria → Antibody-coated bacteria — Matching antibodies: consume, Bacteria: transform.

5. Antibody-coated bacteria + Engulfing white blood cells → White blood cells containing bacterial remains — Antibody-coated bacteria: consume, Engulfing white blood cells: transform.
