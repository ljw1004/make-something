# 5. Cells that send messages

1. Spinal-cord precursor cells + Sonic hedgehog protein → Motor nerve cells — Spinal-cord precursor cells: transform, Sonic hedgehog protein: consume.

2. Motor nerve cells + Gated ion channels → Motor nerve cells [contains Gated ion channels] — Motor nerve cells: preserve, Gated ion channels: consume.

3. Schwann-cell precursors @ Neuregulin-1 protein → Schwann cells — Schwann-cell precursors: transform, Neuregulin-1 protein: fixed context.

4. Motor nerve cells + Schwann cells → Motor nerve cells [contains Gated ion channels, Schwann cells] — Motor nerve cells: preserve, Schwann cells: consume.
