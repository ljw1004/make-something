# 22. Filter, then take back

1. Blood @ Kidney filter → Filtered kidney fluid — Blood: preserve, Kidney filter: fixed context.

2. Filtered kidney fluid @ Kidney recovery tube → Urine — Filtered kidney fluid: transform, Kidney recovery tube: fixed context.

3. Urinary system + Ureters → Urinary system [contains Ureters] — Urinary system: preserve, Ureters: consume.

4. Urinary system + Bladder → Urinary system [contains Ureters, Bladder] — Urinary system: preserve, Bladder: consume.
