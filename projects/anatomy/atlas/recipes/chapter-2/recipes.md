# 2. The powerhouse of the cell

1. Cell + Mitochondria → Cell [contains Nucleus, Mitochondria] — Cell: preserve, Mitochondria: consume.

2. Cell + Sugar-carrier protein → Cell [contains Nucleus, Mitochondria, Sugar-carrier protein] — Cell: preserve, Sugar-carrier protein: consume.

3. Glucose + Cell → ATP — Glucose: consume, Cell: preserve.

4. Cell + Ribosomes → Cell [contains Nucleus, Mitochondria, Sugar-carrier protein, Ribosomes] — Cell: preserve, Ribosomes: consume.

5. ATP + Cell → Protein — ATP: consume, Cell: preserve.
