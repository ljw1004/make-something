# 16. A return route for tissue fluid

1. Tissue beside blood capillaries + Tiny lymph vessels → Tissue with lymph capillaries — Tissue beside blood capillaries: transform, Tiny lymph vessels: consume.

2. Larger lymph vessels + Neck vein segment → Lymph return route — Larger lymph vessels: transform, Neck vein segment: consume.

3. Tissue with lymph capillaries + Lymph return route → Lymph drainage network — Tissue with lymph capillaries: transform, Lymph return route: consume.
